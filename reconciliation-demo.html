Automated Reconciliation Engine

Replaces the manual, spreadsheet-based match between the internal ledger and partner-processor settlement reports — on a unique transaction reference, with amount, currency, status and date tolerances.

Unique reference = match key SFTP / API daily feeds Multi-field tolerance matching Break taxonomy + exceptions

1 · Inputs

Two sources are loaded for a settlement day. In production these arrive automatically — a daily file over SFTP or a pull from the processor's transactions API — and every record carries the unique reference your platform assigned at initiation.

Internal Ledger— records
Your system of record — every transaction your platform initiated, with the reference it stamped at creation.source: core ledger
Processor Reports— records
Combined settlement feeds from partner processors RailPay (bank/card) and NovaRails (stablecoin off-ramp).SFTPAPI

2 · Match rules

Primary match is exact on the unique reference. A matched pair is then validated on amount, currency, status and settlement date — within the tolerances below — before it's cleared.
